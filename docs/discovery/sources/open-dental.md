# Open Dental

- **URL**: https://www.opendental.com/
- **Fecha de investigación**: 2026-11-16

## Problema que resuelve

"Comprehensive, highly customizable dental practice management software at an affordable price for practices of any size" [A].

## Usuarios objetivo

Prácticas dentales de cualquier tamaño; licencia por ubicación (hasta 3 dentistas) [A]. EE.UU. ("Monthly Support Fee (U.S.)") [A].

## Features detectadas

- Aplicación de escritorio (.NET) con base de datos propia, más eServices alojados (Patient Portal, Web Forms, Web Sched, ODMobile, ODTouch) [A]
- Configuración de horarios por profesional; mejoras de bloqueos (v26.3) [A]
- Web Sched: agenda online embebible y link de recall en recordatorios [A]
- eConfirmations: el turno pasa a confirmado automáticamente cuando el paciente responde por texto o email [A]
- **ASAP List**: avisa huecos libres y el paciente reclama o rechaza el turno por link (lista de espera) [A]
- eReminders por texto y email; recall; mensajes de agradecimiento y reseñas [A]
- Odontograma gráfico (3D) con evolución en el tiempo; captura de imágenes [A]
- Clearinghouses de seguros de EE.UU.; Payment Portal; reportes y consultas de usuario [A]
- "100s of Bridges to Other Programs" y conversiones desde más de 200 sistemas [A]
- WhatsApp, Mercado Pago, AFIP/ARCA, español: No evidenciado

## Pricing

USD 199/mes por ubicación con contrato de 12 meses; luego tarifa reducida (monto no publicado); garantía de 90 días; eServices y entrenamiento con costo adicional [A]. Versión de prueba gratuita instalable [A].

## Posicionamiento

"Quality Software for Dental Offices" [A].

## Diferenciadores

Alta personalización, ciclo de releases rápido, conversiones desde 200+ sistemas [A].

El supuesto inicial de que es de código abierto **no se pudo verificar**: ninguna página leída lo dice. El manual (opendental.com/manual) respondió 403 y no se leyó. Es un **referente de confirmación automática y lista de espera** (ASAP List), no un competidor local. Páginas leídas: home, /site/order.html, /site/websched.html, /site/ereminders.html.
