# Curve Dental

- **URL**: https://www.curvedental.com/
- **Fecha de investigación**: 2026-11-16

## Problema que resuelve

"Start on one connected system instead of assembling five": consolidar en un solo sistema tareas dispersas de la práctica dental [A].

## Usuarios objetivo

Prácticas independientes, grupos multisede (DSO) y startups dentales en EE.UU. y Canadá [A]. CD Newco, LLC, Alpharetta, GA (EE.UU.) [A].

## Features detectadas

- 100% nube por navegador, sin servidor local; app Curve Mobile [A]
- Vistas de agenda por **operatorio** (sillón) o profesional; duraciones preseleccionadas por procedimiento; bloqueos; arrastrar y soltar; citas recurrentes [A]
- "Smart Fill" para cubrir huecos de último momento con una lista de aviso corto [A]
- Autoagendamiento del paciente; mensajería de texto bidireccional; recordatorios y confirmaciones [A]
- Recare (controles periódicos), campañas, constructor de flujos, pedidos de reseñas [A]
- Odontograma interactivo, periodontograma, imágenes nativas en la nube, formularios digitales, planes de tratamiento [A]
- Facturación a pacientes y a seguros de EE.UU. (eClaims, ERA, elegibilidad), Curve Pay, analítica [A]
- Multisede "Add locations, not systems" [A]; soporte 24/7/365 [A]
- WhatsApp, Mercado Pago, AFIP/ARCA, español: No evidenciado
