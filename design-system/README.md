# Design system — turnos-odontologia

Mode: deferred
Approval: deferred
Decision source: design-system skill during the Active Orchestrator foundation, 2026-11-17

## Why deferred

The v1 MVP is a REST API and a domain module with no graphical interface (see `knowledge-base/01_vision_y_objetivos.md`, "Fuera de alcance", and `knowledge-base/02_descripcion_general.md`). The assignment does not require a UI. No branding, tokens or mockups are created for now.

## What happens next

At the **first visual change** (for example, the v1.x patient booking page or a staff agenda screen), run the `design-system` skill. It asks once for the durable project-wide policy:

1. `system-and-mockups`: define the visual system and review a mockup for each visual change.
2. `system-only`: define the visual system without routine mockups.
3. `off`: no visual foundation and no mockup requests.

`deferred` is not a permanent opt-out. It is replaced by one of those three choices at that point.
